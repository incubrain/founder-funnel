## Overview

Foundry generates RSS 2.0 feeds for content collections. Feeds are served at `/rss/:collection`.

## Built-in Feed

The layer ships with a `decisions` feed handler that generates an RSS feed from the changelog/decisions collection:

```
GET /rss/decisions → RSS 2.0 XML
```

The feed includes:
- Up to 50 entries ordered by date (newest first)
- Author name from the founder's team profile
- Links to each decision page
- `atom:link` for feed discovery
- 1-hour cache

## Adding RSS to a Page

Set `hasRss: true` in your page frontmatter to add the RSS `<link>` to the page head:

```mdc [content/pages/decisions.mdc]
---
title: Decisions
hasRss: true
---
```

Then add the `ConvertRss` component for subscription:

```mdc
::convert-rss{location="decisions-header" feed-path="decisions"}
::
```

## Subscription Options

The `ConvertRss` component provides a dropdown with reader options:

- Copy Feed URL
- Open Feed (raw XML)
- Subscribe via Feedly, Inoreader, NewsBlur, or The Old Reader

Each selection fires an `offer_click` event for tracking.

## Handler Registry

RSS handlers are registered in `server/utils/rss.handler.ts`. Currently, only the `decisions` handler is built in.

::callout{icon="i-lucide-info" color="info"}
The handler registry is not currently extensible from consuming apps. Custom RSS feeds require modifying the layer source. This is a [known limitation](/docs/advanced/rss).
::

## Feed Format

Generated feeds follow RSS 2.0 with Dublin Core extensions:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<rss version="2.0" xmlns:dc="http://purl.org/dc/elements/1.1/"
     xmlns:atom="http://www.w3.org/2005/Atom">
  <channel>
    <title>Site Name - Collection</title>
    <link>https://yoursite.com</link>
    <description>Feed description</description>
    <atom:link href="..." rel="self" type="application/rss+xml"/>
    <item>
      <title>Entry Title</title>
      <link>https://yoursite.com/decisions/entry</link>
      <guid>https://yoursite.com/decisions/entry</guid>
      <pubDate>Mon, 01 Jan 2026 00:00:00 GMT</pubDate>
      <dc:creator>Author Name</dc:creator>
      <description>Entry description</description>
    </item>
  </channel>
</rss>
```
