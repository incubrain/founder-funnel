## Overview

Foundry includes a full-text content search powered by [Nuxt Content](https://content.nuxt.com){target="_blank"}. The search modal is available site-wide via the header search button or keyboard shortcut.

## Configuration

Control which collections appear in search results via `app.config.ts`:

```ts [app/app.config.ts]
content: {
  collections: {
    searchable: ['docs', 'pages', 'decisions'],
  },
}
```

Only collections listed in `searchable` are indexed. Data collections (FAQ, config, team) are typically not searchable.

## How It Works

1. `useSearch()` composable fetches search sections from all searchable collections
2. Data is loaded lazily on the client (`server: false`) to avoid blocking initial render
3. `app.vue` passes search data to `UContentSearch`
4. The search modal supports keyboard navigation and highlights matches

## Search Button

The search button appears in the header (when `showSearch: true` in navigation config) and in the docs sidebar via `DocsAsideLeftTop`.

Clicking opens the search modal. Keyboard shortcut: `Cmd+K` (Mac) or `Ctrl+K` (Windows/Linux), provided by Nuxt UI.

## Docs Sidebar Search

In the docs layout, a dedicated search button sits at the top of the left sidebar (`DocsAsideLeftBody`). This uses `UContentSearchButton` and opens the same search modal.
