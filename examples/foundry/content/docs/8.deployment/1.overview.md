## Philosophy

Deployment should take less than 5 minutes. If it takes longer, something is wrong.

Foundry is a standard Nuxt application. Anything that can run a Node.js server can host it.

## Build

```bash
pnpm build
```

This produces a `.output/` directory with a self-contained Node.js server.

## Preview

Test the production build locally:

```bash
pnpm preview
```

## Environment Variables

Set these in your hosting provider's dashboard:

| Variable | Required | Description |
|---|---|---|
| `NUXT_PUBLIC_SITE_URL` | Yes | Your production URL |
| `NUXT_WEBHOOK_URL` | If using webhooks | Webhook destination(s) |
| `NUXT_TELEGRAM_CHAT_ID` | If using Telegram | Telegram chat ID |
| `NUXT_PUBLIC_SCRIPTS_UMAMI_ANALYTICS_WEBSITE_ID` | If using Umami | Umami website ID |
| `NUXT_PUBLIC_SCRIPTS_UMAMI_ANALYTICS_SCRIPT_INPUT_SRC` | If using Umami | Umami script URL |

See [Configuration > Environment Variables](/docs/getting-started/configuration#environment-variables) for the full list.

|---|---|---|

For platforms not listed here, see the [Nuxt deployment documentation](https://nuxt.com/deploy){target="_blank"}.
