---

Foundry's theming system is built on [Nuxt UI v3](https://ui.nuxt.com) — a fully-typed component library with accessible primitives, Tailwind CSS v4 theming, and dark mode support out of the box. All of Nuxt UI's components and composables are available in your Foundry project.

For detailed theming customization, see the [Nuxt UI Theming Guide](https://ui.nuxt.com/getting-started/theme).
