## Overview

The layer provides 16 composables across two locations:

- `layer/app/composables/` — 14 app-level composables
- `layer/modules/events/runtime/composables/` — 2 event module composables

All composables are auto-imported by Nuxt. No explicit imports needed.

## Event Tracking

### useEvents

Core event tracking. Wraps events with userId and timestamp, emits `events:track` hook for all providers.

```typescript
const { trackEvent } = useEvents()

await trackEvent({
  id: 'email_submit',
  type: 'form_submitted',
  location: 'hero',
  data: { email: 'user@example.com' },
})
```

**Returns:**

::field-group
  ::field{name="trackEvent" type="(event: Partial<EventPayload>) => Promise<EventResponse>"}
  Track event with auto-populated userId and timestamp.
  ::
::

### useUserIdentity

Anonymous user identity for cross-session tracking. Uses Web Crypto API. SSR-safe.

```typescript
const { getUserId } = useUserIdentity()

const userId = getUserId() // Persisted across sessions
```

**Returns:**

::field-group
  ::field{name="getUserId" type="() => string"}
  Get or create persistent anonymous user ID.
  ::
::

## Content

### useContentConfig

Centralized content configuration and path resolution. All collection name/prefix/routing logic lives here.

```typescript
const { collections, routing, getCollectionForRoute } = useContentConfig()

// Pre-resolved collection names
collections.docs    // e.g., 'docs'
collections.pages   // e.g., 'pages'

// Routing paths
routing.sources     // e.g., '/sources'
routing.offers      // e.g., '/offers'

// Dynamic resolution
const collection = getCollectionForRoute('/docs/getting-started')
```

**Returns:**

::field-group
  ::field{name="collections" type="Record<string, string>"}
  Pre-resolved collection name map.
  ::

  ::field{name="routing" type="Record<string, string>"}
  Pre-resolved routing paths.
  ::

  ::field{name="getCollectionName" type="(key, fallback?) => string"}
  Get collection name by key.
  ::

  ::field{name="getCollectionPrefix" type="(key, fallback?) => string"}
  Get collection URL prefix.
  ::

  ::field{name="getCollectionBackLabel" type="(key, fallback?) => string"}
  Get back-link label.
  ::

  ::field{name="getRoutingPath" type="(key, fallback) => string"}
  Get routing path by key.
  ::

  ::field{name="getSearchableCollections" type="() => string[]"}
  Get searchable collection names.
  ::

  ::field{name="getRoutePatterns" type="() => RoutePatternConfig[]"}
  Build route patterns from prefixes.
  ::

  ::field{name="getCollectionForRoute" type="(path) => string"}
  Map a route path to its collection.
  ::

  ::field{name="resolveInternalPath" type="(path, collection?) => string"}
  Resolve path with collection prefix.
  ::

  ::field{name="flattenNavigation" type="(items?) => ContentNavigationItem[]"}
  Flatten nav tree.
  ::

  ::field{name="getPageMetadata" type="(path) => ContentNavigationItem | null"}
  Get page metadata from navigation.
  ::
::

### useContentPage

Unified content page composable for route-based collection resolution and page data fetching.

```typescript
const { collection, getPage, setContext, context } = useContentPage()

// Fetch page for current route
const { data: page } = await getPage()

// Share context with layouts/components
setContext(page.value)
```

**Returns:**

::field-group
  ::field{name="collection" type="ComputedRef<string>"}
  Current collection based on route.
  ::

  ::field{name="getPage" type="() => AsyncData"}
  Fetch page data for current route.
  ::

  ::field{name="setContext" type="(page, extras?) => void"}
  Update shared page context.
  ::

  ::field{name="context" type="Ref<ContentPageContext | null>"}
  Shared page context state.
  ::
::

### useCitations

Academic citation management per route.

```typescript
const { addCitation, getCitationIndex, getReference } = useCitations()

addCitation('smith-2024')
const index = getCitationIndex('smith-2024') // ComputedRef<number>
const ref = getReference('smith-2024')       // ComputedRef<Reference>
```

**Returns:**

::field-group
  ::field{name="citations" type="ComputedRef<string[]>"}
  Citations for current page.
  ::

  ::field{name="allRefs" type="ComputedRef<Reference[]>"}
  All flattened references.
  ::

  ::field{name="addCitation" type="(id: string) => void"}
  Add citation to page.
  ::

  ::field{name="getCitationIndex" type="(id: string) => ComputedRef<number>"}
  Get 1-indexed citation number.
  ::

  ::field{name="getReference" type="(id: string) => ComputedRef<Reference | undefined>"}
  Get reference object.
  ::

  ::field{name="validateCitation" type="(id: string) => ComputedRef<ValidationStatus>"}
  Validate citation ID.
  ::

  ::field{name="findSimilarIds" type="(id, max?) => ComputedRef<string[]>"}
  Fuzzy search for similar IDs.
  ::
::

### useGlossary

Glossary term fetching and lookup.

```typescript
const { getTerm, resolveGlossaryPath } = useGlossary()

const term = getTerm('mvp')           // ComputedRef<TermWithCategory>
const path = resolveGlossaryPath('mvp') // '/glossary?term=mvp'
```

**Returns:**

::field-group
  ::field{name="glossaryData" type="Ref<GlossaryCollectionItem[] | null>"}
  All glossary data.
  ::

  ::field{name="allTerms" type="ComputedRef<Term[]>"}
  Flattened terms array.
  ::

  ::field{name="allTermsWithCategory" type="ComputedRef<TermWithCategory[]>"}
  Terms with metadata.
  ::

  ::field{name="categoryColors" type="ComputedRef<Record<string, string>>"}
  Category color map.
  ::

  ::field{name="getTerm" type="(termId: string) => ComputedRef<TermWithCategory | undefined>"}
  Get term by ID.
  ::

  ::field{name="resolveGlossaryPath" type="(termId: string) => string"}
  Get glossary URL.
  ::
::

## Forms and Capture

### useFormCapture

Form validation, anti-spam, and submission. Extracts all business logic from `Form.vue`.

```typescript
const { state, schema, isSubmitting, honeypot, handleSubmit } = useFormCapture({
  fields: [{ name: 'email', type: 'email', required: true }],
  location: 'hero',
  offerSlug: 'free-guide',
})
```

**Returns:**

::field-group
  ::field{name="state" type="Reactive<Record<string, string>>"}
  Form field values.
  ::

  ::field{name="schema" type="ComputedRef<ZodSchema>"}
  Dynamic validation schema.
  ::

  ::field{name="isSubmitting" type="Ref<boolean>"}
  Loading state.
  ::

  ::field{name="honeypot" type="Ref<string>"}
  Anti-spam honeypot field.
  ::

  ::field{name="handleSubmit" type="() => Promise<void>"}
  Validate and submit form.
  ::
::

## Social

### useSocialLinks

Maps a socials config object into link objects with platform-appropriate icons.

```typescript
const links = useSocialLinks(computed(() => siteConfig.socials))
// [{ icon: 'i-simple-icons-github', to: 'https://github.com/...', label: 'GitHub', target: '_blank' }]
```

**Returns:** `ComputedRef<SocialLink[]>`

### useSocialShare

Page sharing with clipboard copy and platform links.

```typescript
const { menuItems, share, copyLink, copied } = useSocialShare(
  computed(() => ({ title: 'My Page', description: 'Check this out' }))
)
```

**Returns:**

::field-group
  ::field{name="copied" type="Ref<boolean>"}
  Copy feedback state.
  ::

  ::field{name="shareUrl" type="ComputedRef<string>"}
  Current page URL.
  ::

  ::field{name="menuItems" type="ComputedRef<MenuItem[]>"}
  Share menu options.
  ::

  ::field{name="share" type="(platform: string) => void"}
  Open share link or copy.
  ::

  ::field{name="copyLink" type="() => Promise<void>"}
  Copy URL to clipboard.
  ::
::

### useRssFeed

RSS feed metadata and feeds page URL. Reads config from `rss.feeds` in `nuxt.config.ts`.

```typescript
const { feeds, feedsPageUrl, trackClick } = useRssFeed()
```

**Returns:**

:::field-group
  ::field{name="feeds" type="ComputedRef<RSSFeedInfo[]>"}
  Array of `{ name, url, title, description }` for each configured feed.
  ::

  ::field{name="feedsPageUrl" type="ComputedRef<string>"}
  Route to the feeds listing page.
  ::

  ::field{name="trackClick" type="(location: string) => void"}
  Fire an `offer_click` event.
  ::
:::

## Storage

### useAppStorage

SSR-safe storage abstraction with config-source prefix.

```typescript
const { local, session, getKey } = useAppStorage()

local.set('visited', 'true')
local.get('visited')  // 'true'
local.all()           // All prefixed items
local.clear()         // Clear all prefixed items

// Prefixed key
getKey('visited')     // 'foundry:visited'
```

**Returns:**

::field-group
  ::field{name="local" type="StorageAPI"}
  `get`, `set`, `remove`, `all`, `clear` for localStorage.
  ::

  ::field{name="session" type="StorageAPI"}
  `get`, `set`, `remove`, `all`, `clear` for sessionStorage.
  ::

  ::field{name="getKey" type="(key: string) => string"}
  Get prefixed storage key.
  ::
::

## Development

### useDevConfig

Development-only utilities for inspecting storage state. Returns reduced API in production.

```typescript
const { clearAllStorage, getStorageSnapshot } = useDevConfig()

// Development only
const snapshot = getStorageSnapshot()
await clearAllStorage() // Clears and reloads
```

**Returns:**

::field-group
  ::field{name="clearAllStorage" type="() => Promise<void>"}
  Clear all prefixed storage and reload.
  ::

  ::field{name="getStorageSnapshot" type="() => { localStorage_items, sessionStorage_items }"}
  Get current storage state.
  ::
::
