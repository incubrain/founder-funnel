## Overview

Foundry uses Nuxt's [runtime config](https://nuxt.com/docs/guide/going-further/runtime-config){target="_blank"} for environment variables. Variables prefixed with `NUXT_PUBLIC_` are available client-side. All others are server-only.

## Required Variables

| Variable | Scope | Description |
|---|---|---|
| `NUXT_PUBLIC_SITE_URL` | Public | Your production URL (e.g., `https://mysite.com`). Used for SEO, OG images, and RSS feeds. |

## Webhook Variables

| Variable | Scope | Description |
|---|---|---|
| `NUXT_WEBHOOK_URL` | Server | Webhook destination URL(s). Comma-separated for multiple destinations. Auto-detects platform (Discord, Slack, Telegram). |
| `NUXT_TELEGRAM_CHAT_ID` | Server | Telegram chat ID. Required when using a Telegram bot webhook URL. |

## Analytics Variables

| Variable | Scope | Description |
|---|---|---|
| `NUXT_PUBLIC_SCRIPTS_UMAMI_ANALYTICS_WEBSITE_ID` | Public | Umami website ID for analytics tracking. |
| `NUXT_PUBLIC_SCRIPTS_UMAMI_ANALYTICS_SCRIPT_INPUT_SRC` | Public | Umami script URL (self-hosted or cloud). |

## Logging Variables

| Variable | Scope | Description |
|---|---|---|
| `NUXT_SENTRY_DSN` | Server | Sentry DSN for error tracking and log drain. |
| `NUXT_AXIOM_TOKEN` | Server | Axiom API token for log drain. |
| `NUXT_AXIOM_DATASET` | Server | Axiom dataset name for log drain. |
| `NUXT_POSTHOG_API_KEY` | Server | PostHog API key for log drain. |

## Build Variables

| Variable | Scope | Description |
|---|---|---|
| `NUXT_PUBLIC_CONFIG_SOURCE` | Public | Config source override. Set to `root` or `foundry` to switch between configurations. |
| `CI` | Build | Set to `'true'` to enable CI-specific prerendering behavior. |
| `CI_PRERENDER` | Build | Enables prerender routes during CI builds. |

## Testing Variables

| Variable | Scope | Description |
|---|---|---|
| `VRT_UPDATE` | Test | Set automatically by `pnpm test:vrt:update` to update VRT baselines. |
| `VRT_DEBUG` | Test | Enable VRT server debug logging. |

## Platform Auto-Detection

When `NUXT_PUBLIC_SITE_URL` is not set, Foundry attempts to detect the URL from platform-specific variables:

| Platform | Variable | Example |
|---|---|---|
| Vercel | `NEXT_PUBLIC_VERCEL_URL` | `myapp.vercel.app` |
| Netlify | `URL` | `https://myapp.netlify.app` |
| GitLab Pages | `CI_PAGES_URL` | `https://myorg.gitlab.io/myapp` |
| Cloudflare Pages | `CF_PAGES_URL` | `https://myapp.pages.dev` |

Always set `NUXT_PUBLIC_SITE_URL` explicitly in production for reliable behavior.

## Runtime Config Mapping

Environment variables map to Nuxt runtime config:

```typescript
// nuxt.config.ts (layer defaults)
export default defineNuxtConfig({
  runtimeConfig: {
    // Server-only (NUXT_ prefix)
    webhookUrl: '',       // ← NUXT_WEBHOOK_URL
    telegramChatId: '',   // ← NUXT_TELEGRAM_CHAT_ID

    // Client-accessible (NUXT_PUBLIC_ prefix)
    public: {
      debug: true,
      configSource: '',   // ← NUXT_PUBLIC_CONFIG_SOURCE
      siteUrl: '',        // ← NUXT_PUBLIC_SITE_URL
      scripts: {
        umamiAnalytics: {
          websiteId: '',  // ← NUXT_PUBLIC_SCRIPTS_UMAMI_ANALYTICS_WEBSITE_ID
          scriptInput: {
            src: '',      // ← NUXT_PUBLIC_SCRIPTS_UMAMI_ANALYTICS_SCRIPT_INPUT_SRC
          },
        },
      },
    },
  },
})
```

Access in your code:

```typescript
// Server-side
const { webhookUrl, telegramChatId } = useRuntimeConfig()

// Client or server
const { public: { siteUrl } } = useRuntimeConfig()
```

## .env File

Create a `.env` file in your project root:

```bash [.env]
# Required
NUXT_PUBLIC_SITE_URL=https://mysite.com

# Signal capture
NUXT_WEBHOOK_URL=https://discord.com/api/webhooks/...

# Analytics (optional)
NUXT_PUBLIC_SCRIPTS_UMAMI_ANALYTICS_WEBSITE_ID=abc123
NUXT_PUBLIC_SCRIPTS_UMAMI_ANALYTICS_SCRIPT_INPUT_SRC=https://analytics.mysite.com/script.js
```

Never commit `.env` files. Add `.env` to `.gitignore`.
