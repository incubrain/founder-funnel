## AI Discovering Better Algorithms

### AlphaEvolve — Rewriting the Fundamentals

Google DeepMind's AlphaEvolve is a Gemini-powered evolutionary agent for algorithm discovery. Its results are extraordinary:

::callout{icon="i-lucide-zap" color="primary"}
**32.5% speedup** in FlashAttention kernel performance — directly accelerating AI training itself. A solution already in production **recovers 0.7% of Google's worldwide compute resources**. ([Google DeepMind](https://deepmind.google/blog/alphaevolve-a-gemini-powered-coding-agent-for-designing-advanced-algorithms/))
::

- On 50+ math problems, AlphaEvolve **rediscovered state-of-the-art for 75%** and found **better solutions for 20%**
- Released to Google Cloud in private preview, December 2025

### AlphaDev — Optimizing What Runs Trillions of Times Daily

AlphaDev used reinforcement learning to discover faster sorting algorithms, yielding up to **70% improvement** for short sequences in the C++ Standard Library — the **first update in over a decade**, and the first involving an AI-discovered algorithm. These routines are used **trillions of times every day** worldwide. ([Nature](https://www.nature.com/articles/s41586-023-06004-9))

## The Three Feedback Loops

Recursive self-improvement operates through three interconnected loops, each running at a different speed:

### Loop 1: Software (Days to Weeks)

The fastest loop. AI writes better algorithms, which train better models, which produce better code assistants, which write better algorithms.

::callout{icon="i-lucide-gauge" color="info"}
The software feedback loop alone may sustain **~50% acceleration** in AI progress. OpenAI's release cycle compressed from **six months to under two months**. ([80,000 Hours](https://80000hours.org/articles/how-ai-driven-feedback-loops-could-make-things-very-crazy-very-fast/))
::

### Loop 2: Research (Weeks to Months)

AI discovers better training methods, which produce smarter AI, which discovers even better methods. The ICLR 2026 Workshop on Recursive Self-Improvement — the **first formal academic workshop** on the topic — reflects the field's recognition that this loop is now operational. ([ICLR 2026](https://recursive-workshop.github.io/))

### Loop 3: Hardware (1-2 Years)

AI designs better chip layouts, which train larger models faster, which improve chip design AI. Slower due to fabrication cycles, but durable — and software improvements can **bypass hardware constraints** entirely (AlphaEvolve's 32.5% training speedup delivers hardware-equivalent gains without waiting for new chips).

## Key Takeaways

1. **RSI is deployed, not theoretical.** AI labs are using AI to build AI at scale — 70-90% of Anthropic's code is AI-written, and the first academic workshop on RSI convened at ICLR 2026.

2. **The numbers are step-function advances.** A 56-year math record broken. 2.2 million materials discovered. A decade of biology compressed into 2 days. These are not incremental improvements.

3. **Three loops run simultaneously.** Software (days), research (weeks-months), and hardware (years) — each accelerating the others. Software gains can substitute for hardware gains without fabrication delays.

4. **The pace is itself accelerating.** OpenAI's release cycle compressed from six months to two. Anthropic built a product in 10 days with four engineers. Each loop iteration gets faster.

5. **Safety is the critical constraint.** Dario Amodei warns RSI has "compressed safety timelines to a critical breaking point" — while Anthropic deploys it internally because not doing so means falling behind. The competitive dynamics make voluntary slowdown nearly impossible.

## Compounding Effect: How This Driver Accelerates Others

Recursive self-improvement is unique because it does not just add to progress — it **multiplies every other driver**:

| Driver | How RSI Accelerates It |
|---|---|
| **Hardware & Compute** | AI designs better chips (AlphaChip), optimizes data centers (AlphaEvolve saves 0.7% of Google's compute) |
| **Algorithms** | AI discovers novel algorithms faster than humans (AlphaEvolve, AlphaDev) |
| **Scaling & Data** | AI generates synthetic training data and optimizes data pipelines |
| **Investment** | AI-driven productivity gains justify more spending ($1.4T from OpenAI alone) |
| **Scientific Progress** | AI accelerates discovery across biology, chemistry, materials, and mathematics |
| **Talent** | Each AI researcher multiplies human output — effective lab workforces growing from thousands to tens of thousands |

::callout{icon="i-lucide-trending-up" color="warning"}
Traditional improvements are linear — effort in, proportional returns out. Recursive self-improvement is **exponential**: AI wrote 30% of code in 2025, 70-90% in 2026, and is targeted to be the primary researcher by 2028. Each improvement makes the next one easier and faster. This converts additive progress into multiplicative progress across the entire AI ecosystem.
::

The self-reinforcing investment cycle makes this durable: better AI demonstrates ROI, which attracts more capital, which funds faster improvement, which demonstrates even more ROI. Cursor's revenue explosion from $500M to $2B ARR in 8 months is evidence of this flywheel in action.
