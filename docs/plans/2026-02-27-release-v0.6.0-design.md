## Critical Issues to Fix Before Release

### 1. Missing modules in `layer/package.json` `files` array

**Severity: CRITICAL**

The `files` field only includes `modules/events/`. The 4 new modules (`comments`, `rss`, `changelog`, `docs`) will be **excluded from the npm package**.

Current:
```json
"files": [
  "modules/config.ts",
  "modules/css.ts",
  "modules/events/index.ts",
  "modules/events/runtime",
  "modules/events/server",
]
```

Must add:
```json
"modules/rss/index.ts",
"modules/rss/runtime",
"modules/rss/server",
"modules/changelog/index.ts",
"modules/changelog/runtime",
"modules/docs/index.ts",
"modules/docs/runtime",
```

Note: AGENTS.md, README.md, ARCHITECTURE.md, and issues.md should NOT be included — they're dev-only documentation.

### 2. Legacy "funnel" references

**Severity: MEDIUM**

`my-funnel` is the CLI default directory name. Must be replaced across:

| File | References | Action |
|---|---|---|
| `cli/cli.ts` | `default: 'my-funnel'` | Change to `my-project` |
| `cli/README.md` | Default column says `my-funnel` | Update |
| `cli/test/cli.test.ts` | 4 references to `my-funnel` | Update tests |
| `examples/foundry/content/docs/1.getting-started/1.quickstart.md` | `my-funnel` (3x) | Update |
| `examples/foundry/content/docs/1.getting-started/2.project-structure.md` | `my-funnel/` | Update |
| `examples/foundry/content/docs/7.deployment/1.docker.md` | `my-funnel` (3x) | Update |
| `examples/foundry/content/docs/8.reference/6.cli.md` | `my-funnel` (6x) | Update |
| `examples/foundry/content/docs/8.reference/4.app-config.md` | `Acme Funnels` (3x) | Change to `Acme` |
| `examples/foundry/content/pages/about.md` | `Founder Funnel` (2x) | Context-dependent — this is historical narrative |
| `examples/foundry/content/decisions/10.authority-documentation.md` | `Founder Funnel` | Historical — keep as-is |
| `examples/foundry/content/docs/index.md` | `validation funnel` | Reword |
| `examples/foundry/content/pages/index.md` | `Own Your Funnel` | Reword |

**Decision rules:**
- `my-funnel` → `my-project` (all CLI default dir references)
- `Founder Funnel` in historical content (decisions, about) → keep as-is (it was the old name)
- `funnel` as a concept (marketing funnel, validation funnel, conversion funnel) → keep where semantically correct, reword where it's a product name reference

**Severity: LOW**

2 errors in:
- `examples/astronera/app/components/Carousel.vue` — `@stylistic/arrow-parens`
- `layer/app/components/app/footer/AppFooterBottom.vue` — `@stylistic/member-delimiter-style`

## [0.6.0] - 2026-02-27

### Added

- **RSS module** — Config-driven RSS feed generation from Nuxt Content collections; register feeds in `nuxt.config.ts` with field mapping

- **Docs module** — Glossary terms (`Defn`), inline citations (`Cited`), bibliography, full-text search, and 3-column docs layout; all features toggleable via config
- **Docs navigation middleware** — Auto-redirect to first child page when visiting a docs section root
- **SectionWrapper `reverseBelow` prop** — Responsive layout reversal using VueUse breakpoints; sections stack in reverse order on mobile
- **Webhook retry utility** — Exponential backoff with jitter for webhook delivery
- **CLI copy-list system** — Post-scaffold fetching of shared config files from GitHub with path traversal prevention
- **CLI test suite** — Unit tests for scaffolding and argument parsing
- **Comprehensive documentation** — 9 sections (50+ pages) covering getting started, content, signal capture, theming, advanced, testing, deployment, reference, and modules
- **Starter template enhancements** — Split Hero into sub-components, added app.config.ts, team content, devDependencies for testing
- **CI starter build job** — Validates the scaffolded starter template builds end-to-end
- **Agent smoke test script** — Automated agent functionality testing

### Changed

- **Modular architecture** — Extracted RSS, Changelog, and Docs from layer root into isolated opt-in Nuxt modules under `modules/`
- **Icon packages** — Replaced monolithic `@iconify/json` with individual `@iconify-json/lucide` and `@iconify-json/simple-icons` (peer dependencies)
- **Console → evlog** — All remaining `console.*` calls replaced with evlog structured logging
- **CaseStudy border tokens** — `border-neutral-800` → `border-default` for correct light/dark mode
- **Footer components** — AppFooterBottom and AppFooterLeft restructured
- **ProseA link component** — Simplified implementation
- **MCP tools** — `get-tools.ts` renamed to `get-page.ts`
- **Webhook handler** — Significant rework of `webhook.post.ts`
- **Starter dependency** — Pinned `@incubrain/foundry` to `^0.6.0` (was `latest`)
- **CLI default directory** — `my-funnel` → `my-project`
- **CI security** — Pinned GitHub Actions to commit SHAs
- **Dependencies** — VueUse 14.2.1, minimark 1.0.0, MCP toolkit 0.7.0, Nuxt Content 3.11.2

### Fixed

- **Dynamic Tailwind classes** — PageSplit uses static class map instead of template literal interpolation, preventing build-time purging
- **Citation ID handling** — Fixed citation reference resolution
- **Docs redirect middleware** — Path handling fix
- **Navigation composable** — Minor fix
- **CLI input validation** — Added path traversal prevention, repo/ref/path validation (CodeQL alert fix)
- **Skills install script** — Fixed `npx skills` prompts, added smart management with 24-hour throttle

### Removed

- **InlineTest component** — Removed test component from published package
- **Legacy RSS files** — `convert/Rss.vue`, `useRssFeed.ts`, `rss.handler.ts`, `rss/decisions.ts` moved to RSS module

First public release.

### Features

- **Project scaffolding** — `npx create-foundry [dir]` creates a new Foundry project from starter templates
